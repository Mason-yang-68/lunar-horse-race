## 🚀 一鍵指令速查

### SSH連線
```bash
ssh 您的用戶名@192.168.0.130
```

### 專案目錄
```bash
cd ~/horse-race
```

### 啟動服務
```bash
./start.sh
# 或手動:
python3 server.py &
cloudflared tunnel run horse-race &
```

### 停止服務
```bash
./stop.sh
# 或手動:
pkill -f server.py && pkill -f cloudflared
```

### 查看日誌
```bash
# 遊戲伺服器
tail -f ~/horse-race/server.log

# Cloudflare Tunnel
tail -f ~/horse-race/tunnel.log
```

### 檢查服務狀態
```bash
ps aux | grep server.py
ps aux | grep cloudflared
```

## ❓ 常見問題速查

### Q: 忘記網域名稱？
```bash
cat ~/.cloudflared/config.yml | grep hostname
```

### Q: 忘記Tunnel ID？
```bash
cloudflared tunnel list
```

### Q: 內網訪問正常，外網連不上？
檢查:
1. Tunnel是否運行: `ps aux | grep cloudflared`
2. DNS是否生效（需等5-30分鐘）: `nslookup game.您的網域.tk`
3. Tunnel日誌: `tail -f ~/horse-race/tunnel.log`

### Q: 服務自動停止？
設定開機自動啟動:
- DSM控制台 → 任務排程器 → 新增開機任務
- 指令: `/var/services/homes/您的用戶名/horse-race/start.sh`

### Q: iOS搖晃無反應？
確認:
1. 使用HTTPS訪問（Cloudflare自動提供）
2. Safari允許動作感應權限
3. 不在Private模式

### Q: 想更換網域？
```bash
# 更新DNS
cloudflared tunnel route dns horse-race game.新網域.tk

# 修改config.yml
nano ~/.cloudflared/config.yml
# 更改hostname行

# 修改start.sh
nano ~/horse-race/start.sh
# 更改YOUR_DOMAIN

# 重啟服務
./stop.sh && ./start.sh
```
